# Лабораторная работа 2: Установка Linux

## Тема
Исследование процесса начальной загрузки и установки операционной системы Linux методом bootstrapping.

## Выполнено

### 1. Создание виртуальной машины
- Создана ВМ в VirtualBox: x86_64, 2 GB RAM, 20 GB HDD
- Включена аппаратная виртуализация (VT-x)
- Сетевой адаптер: Bridge
- Подключён ISO-образ System Rescue CD 64-bit

### 2. Установка Linux
- Разметка диска: `/dev/sda1` (boot, 512M), `/dev/sda2` (root, ~19.5G)
- Базовая установка через `pacstrap`
- Настройка `fstab`, `chroot`, локали, часового пояса
- Установка и настройка загрузчика GRUB для UEFI

### 3. Настройка системы
- Установлен и настроен SSH-сервер (`sshd`)
- Создан пользователь `student` с паролем `student`
- Настроен проброс порта: хост `7022` → гость `22`
- Проверено подключение: `ssh student@127.0.0.1 -p 7022`

### 4. Настройка swap-пространства
- Создан swap-файл размером 2 ГБ: `/swapfile`
- Установлены права `600` для безопасности
- Файл активирован командой `swapon`
- Добавлена запись в `/etc/fstab` для автоматического подключения при загрузке
- Проверка: `swapon --show`, `free -h`
