# Лабораторная работа 1
## Исследование компилятора GCC и языка ассемблера

## Цель работы

Исследование работы компилятора GCC, получение ассемблерного кода с различными уровнями оптимизации, изучение связи процесса и операционной системы, работа с Makefile и Git.

---

## Задание

1. Написать программу на C/C++ для вычисления [ваша функция]
2. Скомпилировать программу в ассемблерный код с опциями оптимизации:
   - `-O0` - без оптимизации
   - `-O1` - базовая оптимизация
   - `-O2` - стандартная оптимизация
   - `-O3` - максимальная оптимизация
3. Проанализировать сгенерированный ассемблерный код
4. Создать Makefile для сборки проекта
5. Реализовать параллельные процессы с синхронизацией
