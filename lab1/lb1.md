# Лабораторная работа 1
## Исследование компилятора GCC и языка ассемблера

## Цель работы

Исследование работы компилятора GCC, получение ассемблерного кода с различными уровнями оптимизации, изучение связи процесса и операционной системы, работа с Makefile и Git.

---

## Задание

1. Написать программу на C/C++ для вычисления факториала
2. Скомпилировать программу в ассемблерный код с опциями оптимизации:
   - `-O0` - без оптимизации
   - `-O1` - базовая оптимизация
   - `-O2` - стандартная оптимизация
   - `-O3` - максимальная оптимизация
3. Проанализировать сгенерированный ассемблерный код
4. Создать Makefile для сборки проекта
5. Реализовать параллельные процессы с синхронизацие
---

## Вывод

1. Исследован компилятор GCC — получен и проанализирован ассемблерный код с уровнями оптимизации -O0, -O1, -O2, -O3. Выявлено, что с ростом уровня оптимизации код становится компактнее и эффективнее.
2. Освоен Makefile — создан файл автоматизации сборки с целями для компиляции, запуска и очистки проекта.
3. Изучены процессы ОС — реализовано создание дочерних процессов (fork), межпроцессное взаимодействие (pipe) и синхронизация ресурсов.

**Итог:** получено практическое понимание того, как высокоуровневый код транслируется в машинные инструкции, и как оптимизация влияет на производительность программы.
