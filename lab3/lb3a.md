# Лабораторная работа 3a: Скрипт Bash

## Тема
Реализация скрипта на Bash для поиска строки в текстовых файлах.

## Выполнено

### Скрипт: `search_in_txt.sh`
**Назначение:** Поиск заданной строки во всех `.txt` файлах каталога (рекурсивно).

**Аргументы:**
- `$1` — строка для поиска (обязательный)
- `$2` — каталог для поиска (необязательный, по умолчанию `.`)

**Что делает скрипт:**
1. Проверяет наличие обязательного аргумента и существование каталога
2. Рекурсивно находит все файлы с расширением `.txt`
3. В каждом файле ищет строку (регистронезависимо) через `grep -qi`
4. Пути к найденным файлам сохраняет в `found_files.txt`
5. Выводит результат в консоль
