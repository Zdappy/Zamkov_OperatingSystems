# Лабораторная работа №3b: Скрипт PowerShell

## Тема
Реализация скрипта на PowerShell для поиска строки в текстовых файлах.

## Вариант 4
В текстовых файлах (.txt) найти заданную в параметре сценария строку, из найденных файлов составить список, сохранить его в файл.

## Выполнено

### Скрипт: [3b.ps1](3b.ps1)
**Назначение:** Поиск заданной строки во всех `.txt` файлах каталога (рекурсивно) и сохранение результатов в файл.

**Параметры:**
- `$searchString` — строка для поиска (обязательный)
- `$directory` — каталог для поиска (необязательный, по умолчанию `.`)
- `$outputFile` — файл для сохранения результатов (необязательный, по умолчанию `result.txt`)

**Что делает скрипт:**
1. Рекурсивно находит все файлы с расширением `.txt` в указанном каталоге через `Get-ChildItem`
2. В каждом файле ищет заданную строку через `Select-String`
3. Пути к найденным файлам сохраняет в указанный файл результатов
4. Выводит имена найденных файлов в консоль
